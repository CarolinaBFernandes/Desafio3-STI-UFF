# Cálculo de CR (Java) - STI UFF

Essa é minha solução para o **Desafio 3 da STI UFF**.  
O programa calcula o **Coeficiente de Rendimento (CR)** dos alunos, utilizando um arquivo `.CSV` como base.

## Descrição

O objetivo do projeto é ler um arquivo `.CSV` contendo informações de disciplinas e notas dos alunos, processar esses dados e calcular o **CR (Coeficiente de Rendimento)** de acordo com as regras definidas no desafio.

## ☕ Versão do Java
`25.0.2`
